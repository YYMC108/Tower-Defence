# palette

> 全项目共享调色板。像素游戏的"风格统一"几乎完全取决于调色板统一——
> 三人各自凭感觉取色，最后拼在一起一定显得杂。

详见 [DESIGN.md](res://DESIGN.md) 第 15.7 节。

## 放什么

一份共享色表，建议 **16 ~ 32 色**。推荐格式（挑一种即可）：

- `tower_defence.gpl` —— GIMP / Krita / Aseprite 都能直接导入，纯文本、可读、git 友好 ✅ 推荐
- `tower_defence.png` —— 色块条图，人眼可读，但需要工具才方便取色
- `tower_defence.ase` —— Aseprite 调色板，仅 Aseprite 可用

**`.gpl` 是纯文本**，放进版本管理后，改色能在 git diff 里一眼看出来——这是它比 PNG 色表更好的原因。

## 规则

1. **所有素材从这份调色板取色，不要临时新增颜色。**
2. 新增颜色可以，但要**先提交到调色板**并在群里说一声，让所有人同步——否则你加的颜色别人没有，同屏就会显得不协调。
3. 透明必须用**真 alpha 通道**，不要拿某一种纯色（例如亮品红）当"透明"。理由见 [DESIGN.md](res://DESIGN.md) 第 15.7 节。

## 为什么放在 `assets/` 下而不是散在各处

调色板是**美术和程序都要引用的公共资源**：美术拿它作画，程序可能要用它做团队颜色、血条配色、UI 风格统一。放一处，避免出现"三个版本的调色板"。
